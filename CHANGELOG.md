# Changelog

## 1.0.0

This release contains the current state of the package.

### Contents

- `NoiseTextureGenerator` — UI-independent core with a `Texture2D`, native buffers and preset
  transitions. Public types: `NoiseType`, `NoiseSettings`, `NoiseSettingsBurst`,
  `NoiseCalculationJob` (Burst `IJobParallelFor`).
- `NoiseTextureUpdater` — UI Toolkit adapter, compiled only with `NOISETEXTURE_UIELEMENTS`.
- Three animated noise types: Random, Perlin and Voronoi. Voronoi uses a tiled normalized point
  field driven by `Scale` and `Offset`.
- A `#if NOISETEXTURE_UIELEMENTS` switch driven by asmdef
  `versionDefines` on `com.unity.modules.uielements`; the core also compiles without UI Toolkit.
- EditMode tests for the noise job, animation, Voronoi visibility and the public API.
- `Samples/Demo` with three runnable scenes: UIDocument, Unity 6 PanelRenderer and IMGUI fallback.
  Each scene has self-styled scale/size sliders, noise-type buttons, preset buttons and an unlocked
  cursor. The demo scenes are generated by the **Noise Texture** menu.
- Self-contained demo panel: `NoiseDemoTheme.tss` and `ScaleWithScreenSize` in
  `DemoPanelSettings`. The demo UI and its sliders are built in C#.
- UPM manifest, assembly definitions, README and MIT license.
